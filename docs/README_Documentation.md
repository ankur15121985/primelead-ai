## 🚀 How to Use

### Viewing the HTML Guide
1. Open `PRIMELEAD_AI_Workflow_Guide.html` in any modern browser
2. Use the navigation tabs to explore different sections
3. All animations work automatically

### Creating Word Document
1. Open `PRIMELEAD_AI_Complete_Guide.doc.html` in Microsoft Word
2. Go to **File** → **Save As**
3. Choose **Word Document (.docx)** format
4. Save to your desired location

### Adding Screenshots
The HTML guide includes placeholder areas for screenshots. To add them:
1. Take screenshots of the application
2. Save them in the `screenshots/` folder
3. Update the HTML file to reference the images

## 📸 Taking Screenshots

To capture screenshots of the running application:

1. Start the development server:
   ```bash
   npm run dev
   ```

2. Open http://localhost:5173 in your browser

3. Log in with demo credentials:
   - Email: `owner@primelead.demo`
   - Password: `Demo@1234`

4. Navigate to each section and take screenshots:
   - Homepage
   - Login page
   - Dashboard
   - Leads
   - Pipeline
   - Follow-ups
   - QR Codes
   - Quotations
   - Invoices
   - AI Assistant
   - Integrations
   - Reports
   - Billing
   - Team
   - Settings
   - Admin Panel

5. Save screenshots in `docs/screenshots/` folder
